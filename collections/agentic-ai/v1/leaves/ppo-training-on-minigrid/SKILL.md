# ppo-training-on-minigrid

## Summary

Train Proximal Policy Optimization (PPO) agents on MiniGrid-UnlockPickup under a sparse reward function (+0.5 key pickup, +0.5 door opening, +0.2 goal reach, -0.02 invalid action penalty, plus a step-based bonus), as the baseline RL backbone of the ULPS framework.

## When to use

Use when training or reproducing RL baselines (Unguided PPO, Linear Decay, Q-Learning, DQN) on a sparse-reward MiniGrid-UnlockPickup task and comparing average-reward trajectories via reward AUC.

## When NOT to use

- The task has dense, shaped rewards already available — ULPS and this pipeline target sparse-reward settings where guidance is needed.
- You only need pre-generated paper results: the README notes some results (CSV files and plots) were generated during experimentation and are included under `results/`, not regenerated by a single script.
- The environment is not MiniGrid (e.g., continuous-control or other simulators) — the runners and reward structure are MiniGrid-UnlockPickup specific.

## Inputs

- MiniGrid-UnlockPickup environment (4x4 or 8x8 grid configurations)
- Sparse reward function specification: +0.5 key pickup, +0.5 door opening, +0.2 goal reach, -0.02 invalid action penalty, step-based bonus
- Experiment runner scripts: MainCode/run_4x4_experiment.py and MainCode/run_8x8_experiment.py
- Fine-tuned BERT (bert-base-uncased) action predictor for the Calibrated LLM + PPO variant

## Outputs

- Episode-level training logs (episode_metrics_*.csv)
- Entropy logs (entropy_values_*.csv)
- Calibration metrics (calibration_metrics_*.csv)
- Consolidated AUC table (experiment_auc_summary.csv)
- Training trajectory and radar comparison plots (final_training_summary_*.png)

## How to apply

Launch the experiment runners `MainCode/run_4x4_experiment.py` or `MainCode/run_8x8_experiment.py` with the PPO agent (and the Calibrated LLM + PPO variant for ULPS) on MiniGrid-UnlockPickup, applying the sparse reward function: +0.5 key pickup, +0.5 door opening, +0.2 goal reach, -0.02 invalid action penalty, plus a step-based bonus. Train the comparability baselines (Unguided PPO, Linear Decay, Q-Learning, DQN) in the same environments with the identical reward function so trajectories are directly comparable. During training, write episode-level logs to `episode_metrics_*.csv` along with `entropy_values_*.csv` and `calibration_metrics_*.csv`. Compute reward AUC per method, consolidate into `experiment_auc_summary.csv`, and plot the average-reward trajectory (Fig. 2) and the reward/success/steps/AUC radar comparison (Fig. 3) saved as `final_training_summary_*.png`. The ULPS pipeline additionally blends guidance via Monte Carlo Dropout uncertainty estimation and an entropy-based blending mechanism between the fine-tuned BERT LLM policy and the PPO policy.

## Evaluation signals

- Compute reward AUC per method in experiment_auc_summary.csv; the paper's 4x4 calibrated model should show the highest AUC (2055.08) and lowest average steps to goal (7.24).
- episode_metrics_*.csv must contain per-episode reward, success, and steps records for every trained method (ULPS and all four baselines).
- Generated final_training_summary_*.png plots should reproduce the qualitative result that ULPS achieves higher reward AUC and success rate with fewer environment interactions than Unguided PPO, Linear Decay, Q-Learning, and DQN.
- Reward schedule check: each episode's cumulative reward should reflect +0.5 key pickup, +0.5 door opening, +0.2 goal reach, and -0.02 invalid action penalties plus the step-based bonus.
- Fine-tuning the BERT model should yield more than 9% improvement in execution accuracy, per the abstract's reported gain.

## Limitations

- Not all result files are regenerated automatically by a single script; some results (CSV files and plots) were generated during experimentation and are included under `results/`.
- Some plotting and summarization scripts assume the same output folder structure used during the experiments and may require minor path adjustments locally.
- Only a subset of development plots was selected for the final paper, so additional plots in the repo are not part of the reported figures.
