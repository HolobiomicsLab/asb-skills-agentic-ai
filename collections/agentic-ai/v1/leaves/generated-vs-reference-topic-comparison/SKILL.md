# Generated-vs-reference topic comparison

## Summary

Compares the topics generated by a topic modeling pipeline (e.g., the MALTopic multi-agent LLM framework on the AI-tools survey free-text fields) against reference topics reported in the paper's tables (Tables I and IV) and deposited in the paper's GitHub repository, writing a side-by-side comparison file (topic_comparison.csv).

## When to use

Use when a reproduced topic-modeling run (e.g., MALTopic vs. LDA/BERTopic baselines on survey free text) must be validated against published reference topics to confirm reproducibility of the extracted themes.

## When NOT to use

- Input is raw un-modeled survey text — run the enrichment, topic modeling, and deduplication agents first; this skill only compares already-extracted topics
- The analysis goal is a new topic model rather than verifying reproduction of the published MALTopic topics (Tables I and IV)
- The dataset is not the AI-tools survey free-text fields (concerns/excitement) with corresponding reference topics available

## Inputs

- Refined generated topics from the MALTopic multi-agent pipeline (deduplication agent output) for the concerns and excitement survey free-text fields (N=202)
- Reference topics from Tables I and IV of the MALTopic paper and the yash91sharma/MALTopic GitHub repository

## Outputs

- topic_comparison.csv — side-by-side comparison of generated vs. reference topics

## How to apply

After running the MALTopic pipeline (enrichment agent on the concerns and excitement free-text responses with structured survey fields, then topic modeling and deduplication agents using GPT-4o-mini-2024-07-18 at seed 1234, temperature 0.2, top_p 0.9), collect the refined generated topics. Retrieve the reference topics from Tables I and IV of the MALTopic paper and from the yash91sharma/MALTopic GitHub repository. Align generated topics to reference topics field-by-field (concerns and excitement, N=202) and evaluate agreement using the paper's metrics: word coherence, word diversity, inter-topic similarity, and document coverage. Write the side-by-side comparison to topic_comparison.csv so that divergence between reproduced and reference topics is auditable.

## Related tools

- **MALTopic** (Source of the generated topics being compared and of the reference topics deposited in its GitHub repository) — https://github.com/yash91sharma/MALTopic
- **BERTopic** (Baseline topic modeling technique whose outputs may be included in the comparison against MALTopic topics)
- **openai** (Python client used to configure the GPT-4o-mini-2024-07-18 generation (seed 1234, temperature 0.2, top_p 0.9) that produces the topics under comparison) — https://github.com/openai/openai-python

## Examples

```
python compare_topics.py --generated refined_topics. --reference tables_I_IV.csv --output topic_comparison.csv --metrics word_coherence,word_diversity,topic_similarity,document_coverage
```

## Evaluation signals

- topic_comparison.csv exists and contains side-by-side aligned topics for both free-text fields (concerns and excitement)
- Generated topics reproduce the reference topics from Tables I and IV within the evaluated metrics: word coherence, word diversity, inter-topic similarity, and document coverage
- Reproduced MALTopic topics show increased word coherence and word diversity relative to LDA and BERTopic baselines
- Inter-topic similarity of the reproduced topics is reduced relative to the baselines, matching the paper's finding
- Generation parameters used match the reproducibility configuration: model GPT-4o-mini-2024-07-18, seed 1234, temperature 0.2, top_p 0.9

## Limitations

- Reproduction depends on LLM generation settings; without the fixed seed (1234), temperature (0.2), and top_p (0.9), generated topics may not match the reference topics
- The comparison is specific to the AI-tools survey dataset (N=202) and the two free-text fields; reference topics are not available for other datasets
- Reference topics must be sourced from the published tables and the yash91sharma/MALTopic repository; if those are unavailable, the comparison cannot be grounded
