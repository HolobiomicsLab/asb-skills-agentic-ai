# empathy-subscale-score-averaging

## Summary

A skill for converting an LLM's psychology-based, scale-aware ratings of an essay into a single empathy label: six numeric subscale scores (Batson's sympathetic, moved, compassionate, tender, warm, softhearted) on a 1.0–7.0 scale are parsed and averaged into y* per instance. This underpins the LLM-generated-label (y_llm) training scenario in the LLMPathy empathy-computing pipeline.

## When to use

Use when generating per-instance empathy labels from LLM outputs on NewsEmp22/23/24 essays using a Batson six-subscale scale-aware prompt, or when aligning LLM-generated labels with dataset instance identifiers for training.

## When NOT to use

- The task is training or testing the RoBERTa/DeBERTa PLM on already-generated labels (use config/config_test.yaml and python src/test.py instead).
- Labels are crowdsourced baseline labels for the y(202x) or y'(202x) scenarios rather than LLM-generated labels.
- The emotion taxonomy is not Batson's six-subscale empathy protocol, so six 1.0–7.0 subscale scores cannot be elicited.

## Inputs

- Essay texts and instance identifiers (message IDs, article IDs, speaker IDs) from NewsEmp22, NewsEmp23, NewsEmp24 (Codalab competition pages)
- Scale-aware prompt template with Batson's six subscales: sympathetic, moved, compassionate, tender, warm, softhearted (Table I)
- config/config_common.yaml specifying the LLM-generated label column name

## Outputs

- Per-instance averaged empathy label y* with its instance identifier, written to data/llm-generated-labels
- Six per-essay numeric subscale scores in the 1.0–7.0 range, validated for count and range

## How to apply

Load each essay text with its instance identifiers (message IDs, article IDs, speaker IDs) from the NewsEmp22, NewsEmp23 and NewsEmp24 datasets obtained from their Codalab competition pages, since the public datasets restrict redistribution and must be matched back via IDs. Build a scale-aware prompt pairing the essay with the Batson six-subscale template (Table I) and query the LLM with deterministic sampling (temperature 0, top_p 0.01) so each essay yields exactly six comma-separated numeric subscale scores between 1.0 and 7.0. Parse the six scores, verify six numeric values were returned, and average them into a single empathy score y* per instance. Write the records to a labels file in data/llm-generated-labels with column naming consistent with the LLM-generated label column configured in config/config_common.yaml (the y_llm scenario), so the labels can be used directly for the training-data-augmentation experiments.

## Evaluation signals

- Each LLM response parses to exactly six numeric comma-separated values; otherwise the prompt/sampling settings (temperature 0, top_p 0.01) must be re-checked.
- Every subscale score falls within the valid 1.0–7.0 numeric range for Batson's six subscales.
- Every output record contains an instance identifier, the six subscale scores, and the averaged y*, and identifiers match back to the original NewsEmp22/23/24 dataset IDs.
- The output file exists in data/llm-generated-labels and its label-column name matches the y_llm configuration in config/config_common.yaml.
- Downstream y_llm runs (e.g. y(2022)+y_llm(2024)-gpt style experiments) can load the labels without schema errors.

## Limitations

- The public NewsEmp22/23/24 datasets restrict redistribution, so only LLM-generated labels aligned with dataset IDs are provided; the full essays must be obtained separately from Codalab.
- Paper erratum: peak RMSE scores reported in Tables V and VIII of the published version were corrected in the repository; corrected values show even better results than claimed in the published paper.
- Label files are dataset-specific (message IDs, article IDs, speaker IDs differ per dataset), so records cannot be mixed across datasets without re-aligning identifiers.
