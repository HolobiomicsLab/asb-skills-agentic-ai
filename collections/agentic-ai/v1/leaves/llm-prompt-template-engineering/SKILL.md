# llm-prompt-template-engineering

## Summary

Design and A/B-test plain versus psychology-based 'scale-aware' prompt templates to elicit numeric empathy scores from LLMs (GPT-4, Llama 3 70B) in zero-shot mode on the NewsEmp benchmark splits, then quantify template effectiveness with PCC, CCC, and RMSE against gold labels.

## When to use

Use when you need to predict a graded human judgement (e.g., empathy scores on a 1-7 scale) from text via zero-shot LLM prompting, and must choose between a plain instruction and a psychology-grounded scale-aware rubric prompt.

## When NOT to use

- The task is fine-tuned classification or regression rather than zero-shot prompting — use the PLM training pipeline (RoBERTa/DeBERTa with LLM-generated labels) instead
- The evaluation target is binary or categorical labels rather than a graded empathy score, since PCC/CCC/RMSE template comparison presumes numeric targets
- You need to redistribute the datasets themselves — the Codalab NewsEmp data restricts redistribution, so only ID-aligned generated labels can be shared

## Inputs

- NewsEmp22/23/24 validation and test splits downloaded from Codalab competition dataset pages
- Plain prompt template and psychology-based scale-aware prompt template (Table I)
- Instance identifiers (message IDs, article IDs, speaker IDs) for aligning predictions with gold labels
- Gold empathy scores from the source datasets

## Outputs

- Per-instance zero-shot empathy score predictions from each LLM x template combination
- Results table mirroring Table VII (PCC, CCC, RMSE per model x prompt-template x dataset), e.g., table_vii_metrics.csv

## How to apply

Download the NewsEmp22/NewsEmp23/NewsEmp24 validation and test splits from their Codalab competition pages, then format every instance with both the plain template and the psychology-based scale-aware template (Table I of the paper), which anchors the rating scale with psychological framing. Run zero-shot inference with GPT-4 and Llama 3 70B (no fine-tuning or gradient updates) to obtain one empathy score per instance, and match each prediction back to its original instance identifier (message ID, article ID, or speaker ID) using ID-aligned files as done in the LLMPathy repository. Compute Pearson correlation coefficient (PCC), concordance correlation coefficient (CCC), and RMSE between predicted and gold scores for every model x template x dataset cell. Decision point: a scale-aware template is adopted when it improves PCC/CCC and reduces RMSE over the plain prompt — on NewsEmp24 test, PCC rose from 0.405 to 0.441, CCC from 0.358 to 0.436, and RMSE fell from 1.859 to 1.731 (GPT-4 reached PCC 0.581).

## Evaluation signals

- All dataset x model x template cells in the results table are populated (no missing combinations)
- Computed PCC/CCC/RMSE values match the Table VII reference values reported in the paper (output_matches_reference check)
- Scale-aware prompt improves over the plain prompt on NewsEmp24 test: PCC 0.441 > 0.405, CCC 0.436 > 0.358, RMSE 1.731 < 1.859
- Every generated prediction maps back to a valid original dataset instance identifier (message ID, article ID, or speaker ID) before metric computation
- Zero-shot runs involve no gradient updates or fine-tuning checkpoints

## Limitations

- Zero-shot prompting underperforms fine-tuned PLMs trained on (noise-reduced or LLM-generated) labels — the state-of-the-art RoBERTa PCC on NewsEmp is 0.648 versus zero-shot PCC 0.581 with GPT-4
- Public NewsEmp datasets restrict redistribution, so only LLM-generated labels aligned to original IDs can be shipped; the source data must be obtained from Codalab
- Prompt-template effectiveness is dataset- and scale-specific: the reported scale-aware gains were measured with the paper's specific 1-7 empathy scale and Table I templates
