# zero-shot-empathy-score-prediction

## Summary

Reproduces Table VII-style zero-shot empathy score prediction on the NewsEmp validation/test splits using GPT-4 and Llama 3 70B with plain and psychology-based scale-aware prompt templates, evaluated with PCC, CCC, and RMSE against gold empathy scores.

## When to use

Use when you need to benchmark how well a large language model (e.g., GPT-4, Llama 3 70B) predicts per-instance empathy scores without any fine-tuning, and to test whether a scale-aware prompt beats a plain prompt.

## When NOT to use

- The task is supervised empathy regression with training — use the repo's RoBERTa/DeBERTa PLM training pipeline (PCC 0.648 state-of-the-art) instead of zero-shot prompting
- The input dataset is not one of the NewsEmp22/23/24 empathy benchmarks with empathy-score gold labels
- The prompts are being reused to generate training labels rather than to evaluate zero-shot prediction — that is the label-generation scenario, not this evaluation skill

## Inputs

- NewsEmp22 validation and test splits (Codalab competition 834)
- NewsEmp23 validation and test splits (Codalab competition 11167)
- NewsEmp24 validation and test splits (Codalab competition 18810)
- Plain and scale-aware prompt templates (Table I of the paper)
- Model outputs from GPT-4 and Llama 3 70B zero-shot inference

## Outputs

- One predicted empathy score per dataset instance, keyed by message ID / article ID / speaker ID
- table_vii_metrics.csv with PCC, CCC, and RMSE for each dataset x model x prompt-template combination

## How to apply

Download the NewsEmp22, NewsEmp23, and NewsEmp24 validation and test splits from their Codalab competition pages (the repo itself cannot redistribute them). Format each instance into prompts using both the plain and the psychology-based scale-aware templates from Table I of the paper. Run zero-shot inference with GPT-4 and Llama 3 70B — no fine-tuning or gradient updates — to produce one empathy score per instance. Match each generated prediction back to its original dataset identifier (message ID, article ID, or speaker ID), since the repo distributes LLM outputs aligned with original IDs rather than full texts. Compute Pearson correlation coefficient (PCC), concordance correlation coefficient (CCC), and root-mean-square error (RMSE) for every dataset x model x prompt-template combination, and assemble a results table mirroring Table VII (e.g., table_vii_metrics.csv). The scale-aware prompt is expected to improve over the plain prompt (on NewsEmp24 test, PCC 0.405 -> 0.441, CCC 0.358 -> 0.436, RMSE 1.859 -> 1.731 for Llama 3 70B; GPT-4 reaches PCC 0.581).

## Evaluation signals

- Computed PCC/CCC/RMSE in table_vii_metrics.csv match the Table VII reference values (output_matches_reference)
- All dataset x model x prompt-template cells are populated (no empty combinations)
- Scale-aware prompt improves over plain prompt: NewsEmp24 test PCC 0.405 -> 0.441, CCC 0.358 -> 0.436, RMSE 1.859 -> 1.731
- Every generated prediction is matched back to an original dataset instance identifier (message ID, article ID, or speaker ID)
- No gradient updates or fine-tuning steps appear in the pipeline — inference only

## Limitations

- The public NewsEmp datasets restrict redistribution, so the full datasets are not in the repository and must be obtained from the Codalab competition pages
- Zero-shot LLM prediction underperforms the trained RoBERTa PLM pipeline, which reaches a state-of-the-art PCC of 0.648 on the NewsEmp benchmarks
- The README notes errors in reporting of peak RMSE scores affecting Tables V and VIII of the published paper; verify against the corrected tables, and treat published Table VII values with similar caution
