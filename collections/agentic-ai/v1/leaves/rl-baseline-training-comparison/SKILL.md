# rl-baseline-training-comparison

## Summary

Trains and logs standard RL baselines (Unguided PPO, Linear Decay, Q-Learning, DQN) under identical MiniGrid-UnlockPickup settings as the ULPS agent so reward AUC, success rate, and steps-to-goal can be compared fairly. It operationalizes the paper's claim that uncertainty-aware LLM guidance beats unguided, uncalibrated, and standard RL baselines.

## When to use

Use when benchmarking a new sparse-reward RL agent (e.g., LLM-guided policy shaping) against standard RL baselines and you need per-episode logs plus a consolidated AUC/success-rate comparison table on MiniGrid-UnlockPickup.

## When NOT to use

- You only need to re-plot existing results — the results/ folder already contains pre-generated CSV logs and plots, and not all files are regenerated by a single script
- Your environment or reward function differs from MiniGrid-UnlockPickup with the sparse reward scheme, since the baseline comparability argument depends on identical environments and rewards
- You need automatic end-to-end regeneration of every result file from one command; the README explicitly notes this is not supported

## Inputs

- MiniGrid-UnlockPickup environments at 4x4 and 8x8 grid sizes
- Baseline agent implementations in Qlearning/ and DQN/ folders plus PPO variants (Unguided PPO, Linear Decay)
- Shared sparse reward function spec (+0.5 key pickup, +0.5 door opening, +0.2 goal reach, -0.02 invalid action, step-based bonus)
- Fixed training protocol: 1000 episodes, seed 42, 50-step episode cap

## Outputs

- episode_metrics_*.csv (per-episode logs per method)
- entropy_values_*.csv and calibration_metrics_*.csv logs
- experiment_auc_summary.csv (one row per method per grid size with reward AUC, success rate, average steps to goal, average reward, total wins, total steps)
- final_training_summary_*.png comparison plots

## How to apply

Run each baseline agent (Unguided PPO, Uncalibrated LLM, Linear Decay PPO, Q-Learning from Qlearning/, DQN from DQN/) in both the 4x4 and 8x8 MiniGrid-UnlockPickup environments under identical conditions: 1000 episodes, fixed seed 42, and a 50-step episode cap. Apply the same sparse reward function to all methods (+0.5 key pickup, +0.5 door opening, +0.2 goal reach, -0.02 invalid action penalty, plus a step-based bonus) so comparisons are apples-to-apples. During each run, write episode-level logs (episode_metrics_*.csv) plus entropy_values_*.csv and calibration_metrics_*.csv. Aggregate per-episode results into per-method summary metrics — reward AUC, success rate, average steps to goal, average reward, total wins, total steps — matching the columns of Table II, and write them to experiment_auc_summary.csv. The rationale is that identical seeds, episode caps, and reward functions are what make the AUC and success-rate deltas attributable to the guidance mechanism rather than training-protocol differences.

## Evaluation signals

- experiment_auc_summary.csv exists with exactly one row per method per grid size (4x4 and 8x8)
- All methods were run under identical settings: 1000 episodes, seed 42, 50-step episode cap, same reward function
- ULPS rows show higher reward AUC and success rate than unguided PPO, uncalibrated LLM, Q-Learning, and DQN (e.g., 99.7% ULPS success vs 72.3% uncalibrated LLM and near-total PPO failure in 8x8)
- episode_metrics_*.csv, entropy_values_*.csv, and calibration_metrics_*.csv are produced for each method during training
- Final figures (final_training_summary_*.png) reproduce the qualitative result that ULPS achieves higher AUC with fewer environment interactions

## Limitations

- Not all result files are regenerated automatically by a single script; some CSVs and plots were pre-generated during experimentation and are shipped under results/
- Plotting and summarization scripts assume the same output folder structure used during the experiments and may require minor path adjustments
- Several additional plots were generated during development but only a subset was selected for the final paper, so the repo does not contain every intermediate comparison
