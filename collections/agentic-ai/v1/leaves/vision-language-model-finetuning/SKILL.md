# vision-language-model-finetuning

## Summary

Fine-tuning pipeline for EVL-MCoT, a vision-language multi-CoT model for harmful meme detection, which fuses frozen Long-CLIP visual/text features with Multi-CoT reasoning from an MLLM (LLaVA-1.5-7B or GPT-4) and trains with AdamW under a cosine schedule on Hateful Memes and MultiOFF.

## When to use

Use when fine-tuning a multimodal meme-classification model that must fuse frozen Long-CLIP visual features with Multi-CoT text reasoning from an MLLM, and report ACC/AUROC (Hateful Memes) or ACC/F1 (MultiOFF).

## When NOT to use

- The task is a standard CLIP-style meme classifier with short (<20 token) prompts and no CoT reasoning, where Long-CLIP's 248-token context and multi-CoT generation add unnecessary cost
- The dataset is not meme-style multimodal image+text data (e.g., pure text or pure vision benchmarks); the prototype-guided and context-guided decoders assume paired image and text features
- No MLLM (LLaVA-1.5-7B or GPT-4) is available for generating Multi-CoT chains, since the training features depend on those reasoning sequences

## Inputs

- Hateful Memes dataset (10,000+ multimodal meme examples labeled hateful/non-hateful; Test Seen and Test Unseen splits)
- MultiOFF dataset (743 memes labeled offensive/non-offensive)
- Multi-CoT reasoning chains generated by LLaVA-1.5-7B (Hateful Memes) or GPT-4 (MultiOFF) with n=3, m=3
- Long-CLIP text embeddings of hateful and benign template text (248-token context)
- Frozen Long-CLIP visual encoder features for meme images

## Outputs

- Trained EVL-MCoT model weights per configuration (full model and ablation variants)
- Accuracy and AUROC on Hateful Memes Test Seen (full model: 75.88 ACC / 79.25 AUROC)
- Accuracy and F1 on MultiOFF (full model: 70.0 ACC / 63.8 F1)
- Ablation results table with one row per removed component (Long-CLIP, prototype-guided decoder, context-guided decoder, multi-CoT)

## How to apply

Clone github.com/BGWH123/EVL-MCoT and use the core training pipeline in the train/ directory. Generate Multi-CoT chains (n=3, m=3 setting) with LLaVA-1.5-7B for Hateful Memes or GPT-4 for MultiOFF, then encode hateful and benign text templates with the frozen Long-CLIP text encoder (248-token context, chosen because standard CLIP fails beyond 20 tokens while CoT sequences are ~150 words). Train with the AdamW optimizer at learning rate 5e-5, weight decay 0.01, and a cosine learning rate scheduler, using batch size 8 with gradient accumulation every 2 steps on NVIDIA RTX 3090/4090 GPUs. For ablation variants, swap n,m pairs (n=1,m=1; n=1,m=3; n=3,m=1), drop the context-guided attention layer or the prototype-guided token fusion decoder, or replace Long-CLIP with standard CLIP.

## Related tools

- **Long-CLIP** (Frozen visual and text encoder extending context to 248 tokens; encodes hateful/benign text templates and extracts visual representations for fusion)
- **LLaVA-1.5-7B** (MLLM used to generate Multi-CoT reasoning chains for the Hateful Memes experiments (n=3, m=3 setting))
- **GPT-4** (MLLM used to generate Multi-CoT reasoning chains for the MultiOFF experiments (n=3, m=3 setting))
- **AdamW** (Optimizer for fine-tuning: learning rate 5e-5, weight decay 0.01, cosine learning rate scheduler)
- **CLIP** (Baseline encoder for the ablation in which Long-CLIP is removed; limited to 20-token inputs, illustrating the need for Long-CLIP)

```
git clone https://github.com/BGWH123/EVL-MCoT && cd EVL-MCoT && python train/train.py --mllm llava-1.5-7b --n 3 --m 3 --lr 5e-5 --batch-size 8 --grad-accum 2
```

## Evaluation signals

- Full-model reproduction: 75.88 accuracy / 79.25 AUROC on Hateful Memes Test Seen and 70.0 accuracy / 63.8 F1 on MultiOFF within tolerance
- Every ablated row (Long-CLIP removed: 68.68 ACC / 71.77 AUROC on Hateful Memes Test Seen; 62.60 ACC / 59.19 F1 on MultiOFF) shows an expected metric drop relative to the full model
- CoT ablation trend: reducing the multi-CoT pair settings (n=1,m=1; n=1,m=3; n=3,m=1) yields lower ACC/AUROC than the n=3,m=3 configuration
- Training invariants: AdamW at lr 5e-5 with weight decay 0.01 and cosine scheduler; batch size 8 with gradient accumulation every 2 steps
- Text features must fit within Long-CLIP's 248-token context even though CoT sequences are ~150 words, which standard CLIP (20-token limit) cannot accommodate

## Limitations

- Repository is incomplete: only the train/ directory (training pipeline, model initialization, training loop, logging, evaluation) is available; models/, configs/, and scripts/ are listed as 'coming soon', with no requirements.txt or pretrained weights
- Future work is to shorten the reasoning chains while maintaining performance, indicating current multi-CoT chains are costly to generate
- Removing Long-CLIP forces standard CLIP, which struggles with inputs exceeding 20 tokens, so the 150-word CoT sequences cannot be processed correctly in that ablation
