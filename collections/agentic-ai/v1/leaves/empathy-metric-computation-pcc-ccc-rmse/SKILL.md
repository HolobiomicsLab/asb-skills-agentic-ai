# empathy-metric-computation-pcc-ccc-rmse

## Summary

Zero-shot evaluation of LLM empathy-score prediction on the NewsEmp22/23/24 validation and test splits, computing Pearson correlation coefficient (PCC), concordance correlation coefficient (CCC) and root-mean-square error (RMSE) between predicted and gold empathy scores, and assembling the results into a Table VII-style comparison of plain vs. psychology-based scale-aware prompts.

## When to use

Use when you have per-instance LLM empathy predictions (no fine-tuning) for NewsEmp22/23/24 validation or test splits and need to reproduce the paper's zero-shot Table VII comparison of prompt templates and models.

## When NOT to use

- You are evaluating fine-tuned PLMs (RoBERTa/DeBERTa) on the same NewsEmp data — that corresponds to Tables II–V and VIII of the paper, not the zero-shot Table VII protocol
- Your LLM outputs have not been matched back to original dataset instance identifiers, so predicted and gold scores cannot be paired instance-by-instance
- You only need the paper's corrected peak RMSE values for Tables V/VIII, which the README updates separately from Table VII

## Inputs

- NewsEmp22, NewsEmp23 and NewsEmp24 validation and test splits from the Codalab competition dataset pages
- Plain and psychology-based scale-aware prompt templates (Table I of the paper)
- Zero-shot empathy score predictions from GPT-4 and Llama 3 70B, aligned to instance identifiers
- Gold empathy scores per instance

## Outputs

- table_vii_metrics.csv with PCC, CCC and RMSE for every LLM x prompt-template x dataset combination
- Per-instance prediction-to-gold mapping keyed by message ID, article ID or speaker ID

## How to apply

Download the NewsEmp22, NewsEmp23 and NewsEmp24 validation and test splits from their Codalab competition pages (competitions 834, 11167 and 18810). Format each instance into prompts using both the plain prompt and the psychology-based scale-aware prompt template (Table I of the paper), then run zero-shot inference with GPT-4 and Llama 3 70B — no fine-tuning and no gradient updates — to get one empathy score per instance. Match each generated prediction back to its original dataset instance identifier (message ID, article ID or speaker ID), which is possible because the authors distribute LLM-generated labels 'aligned with the original dataset IDs, so they can be easily matched back to the source data'. Compute PCC, CCC and RMSE between predicted and gold empathy scores for every LLM x prompt-template x dataset combination, and assemble the values into a table mirroring Table VII (reference: scale-aware prompt improves test PCC from 0.405 to 0.441, CCC from 0.358 to 0.436, RMSE from 1.859 to 1.731 for Llama 3 70B; GPT-4 reaches PCC 0.581).

## Evaluation signals

- Every dataset x model x prompt-template cell of table_vii_metrics.csv is populated for NewsEmp22/23/24 validation and test splits
- Computed zero-shot test-split values match the Table VII reference: Llama 3 70B scale-aware prompt PCC 0.441, CCC 0.436, RMSE 1.731; plain prompt PCC 0.405, CCC 0.358, RMSE 1.859
- GPT-4 zero-shot test PCC equals 0.581 on NewsEmp24
- The scale-aware prompt improves PCC and CCC and lowers RMSE relative to the plain prompt (RMSE decreases from 1.859 to 1.731)
- Each prediction row pairs to a gold empathy score via the original dataset identifier (message ID, article ID or speaker ID), with no unmatched predictions

## Limitations

- The public NewsEmp datasets restrict redistribution, so the repository only ships LLM-generated labels aligned to original IDs; the full splits must be obtained from the Codalab competition pages (834, 11167, 18810)
- The README reports minor errors in the published peak RMSE values affecting Tables V and VIII, so cross-checking against the published version alone can be misleading
- Zero-shot numbers are sensitive to prompt template choice: the scale-aware prompt is what drives the improvement over plain prompting, so plain-prompt baselines understate achievable performance
