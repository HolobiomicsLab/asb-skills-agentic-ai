# gridworld-benchmark-experimentation

## Summary

A reproducible benchmarking workflow for comparing an uncertainty-aware LLM-guided RL agent (ULPS: calibrated BERT LLM blended with PPO) against Unguided PPO, Uncalibrated LLM, Linear RL PPO, Q-Learning, and DQN baselines on MiniGrid-UnlockPickup in 4x4 and 8x8 grids, producing per-episode CSV logs and a consolidated experiment_auc_summary.csv matching Table II.

## When to use

Use when reproducing or extending the sparse-reward MiniGrid-UnlockPickup comparison of ULPS versus PPO/Q-Learning/DQN baselines across 4x4 and 8x8 grid sizes, or when aggregating episode-level RL logs into reward AUC and success-rate tables.

## When NOT to use

- The task targets dense-reward or non-gridworld RL benchmarks (e.g. Atari or continuous control); ULPS and these baselines were designed and evaluated only on MiniGrid-UnlockPickup.
- Only pre-generated artifacts under results/ are needed for inspection rather than new runs — regenerating them requires manual path fixes since a single script does not regenerate all result files.

## Inputs

- MainCode/run_4x4_experiment.py and MainCode/run_8x8_experiment.py experiment runners
- Qlearning/ baseline implementation
- DQN/ baseline implementation
- MiniGrid-UnlockPickup environment (4x4 and 8x8 grid sizes)
- Fixed run settings: 1000 episodes, seed 42, 50-step episode cap

## Outputs

- episode_metrics_*.csv (episode-level logs)
- entropy_values_*.csv (entropy logs)
- calibration_metrics_*.csv
- final_training_summary_*.png plots
- experiment_auc_summary.csv (per-method, per-grid-size summary matching Table II)

## How to apply

Run the experiment runners `MainCode/run_4x4_experiment.py` and `MainCode/run_8x8_experiment.py`, which implement ULPS (fine-tuned BERT action predictor with Monte Carlo dropout uncertainty and entropy-based blending over PPO) and the baselines from `Qlearning/` and `DQN/`. Hold settings fixed across all methods: 1000 episodes, seed 42, and a 50-step episode cap in both grid sizes so comparisons are like-for-like. During each run, capture episode-level logs (`episode_metrics_*.csv`), entropy logs (`entropy_values_*.csv`), and calibration metrics (`calibration_metrics_*.csv`). Aggregate per-episode results into per-method summaries (reward AUC, success rate, average steps to goal, average reward, total wins, total steps) and write the cross-method, cross-environment table to `experiment_auc_summary.csv` with final plots (`final_training_summary_*.png`). Because not all result files are regenerated by a single script, some CSVs and plots under `results/` are pre-generated and plotting scripts may need path adjustments.

## Evaluation signals

- experiment_auc_summary.csv exists with exactly one row per method per grid size (4x4 and 8x8).
- ULPS rows show higher reward AUC and success rate than Unguided PPO, Uncalibrated LLM, Linear RL PPO, Q-Learning, and DQN rows.
- In the 8x8 environment, expect Unguided PPO to fail almost completely, Uncalibrated LLM near 72.3% success, and ULPS near 99.7% success.
- All methods were run under identical settings (1000 episodes, seed 42, 50-step cap), so per-method episode counts and total-steps columns are directly comparable.
- Expected side artifacts are present: episode_metrics_*.csv, entropy_values_*.csv, calibration_metrics_*.csv, and final_training_summary_*.png.

## Limitations

- Not all result files are regenerated automatically by a single script; some CSVs and plots were pre-generated during experimentation and included under results/.
- Some plotting and summarization scripts assume the same output folder structure used during the experiments and may require minor path adjustments.
- Several additional plots were generated during development, but only a subset was selected for the final paper for compactness.
- No changelog found in the repository, so provenance of result files is limited.
