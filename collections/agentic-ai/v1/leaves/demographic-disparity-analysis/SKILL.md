# demographic-disparity-analysis

## Summary

Quantifies whether agreement between crowdsourced and LLM-generated empathy labels (Concordance Correlation Coefficient) varies across annotator demographic groups (gender, education, race, age, income) on the combined NewsEmp24 dataset, exposing demographic biases in LLM label generation.

## When to use

Use when comparing crowdsourced vs LLM-generated labels and you need to check whether agreement is equitable across demographic subgroups rather than reported as a single global statistic.

## When NOT to use

- You only need a global agreement score between crowdsourced and LLM labels (e.g., a single Pearson/CCC) with no demographic breakdown.
- Your labels come from a dataset other than the NewsEmp24 (CodaLab competition 18810) setup and no annotator demographic metadata is available to join on.
- You are evaluating downstream model performance (RoBERTa/DeBERTa empathy prediction) rather than agreement between two label sources per demographic group.

## Inputs

- NewsEmp24 crowdsourced empathy labels from CodaLab competition 18810 (https://codalab.lisn.upsaclay.fr/competitions/18810)
- LLM-generated label files from data/llm-generated-labels (labels paired with instance identifiers such as message IDs, article IDs, speaker IDs)
- Annotator demographic metadata covering gender, education, race, age, and income

## Outputs

- demographic_disparity_ccc.csv with per-group CCC values and per-group sample counts

## How to apply

Load the NewsEmp24 crowdsourced labels from the CodaLab competition 18810 and the LLM-generated label files under data/llm-generated-labels, which pair generated labels with instance identifiers (message IDs, article IDs, speaker IDs). Merge the crowdsourced labels, LLM labels, and annotator demographic metadata (gender, education, race, age, income) using a pandas join keyed on the dataset-specific IDs, using Python 3.10.12. Stratify the joined records by each demographic attribute to form annotator subgroups, then compute the Concordance Correlation Coefficient (CCC) between crowdsourced and LLM labels within each subgroup along with the per-group sample counts. Write the per-group CCC values and counts to demographic_disparity_ccc.csv; CCC values must lie within [-1, 1] and each count must equal the number of joined records for that group. The paper's finding is that CCC is similar across gender and education but varies widely across race, age and income, even turning negative for two race categories.

- **pandas** (Join crowdsourced labels, LLM-generated labels, and demographic metadata on shared instance identifiers; stratify records into demographic subgroups) — https://github.com/hasan-rakibul/LLMPathy

## Examples

```
import pandas as pd; merged = cs.merge(llm, on='instance_id').merge(demo, on='annotator_id'); merged.groupby(['race']).apply(lambda g: ccc(g['cs_label'], g['llm_label'])).to_csv('demographic_disparity_ccc.csv')
```

## Evaluation signals

- demographic_disparity_ccc.csv exists and contains both ccc and sample-count fields.
- Every computed CCC value lies within [-1, 1].
- Each reported group count equals the number of joined records for that demographic group.
- Results reproduce the paper's pattern: similar CCC across gender and education groups, wide variation across race, age, and income groups, with negative CCC for two race categories.

## Limitations

- The original NewsEmp datasets restrict redistribution, so the repository only ships LLM-generated labels aligned with original dataset IDs; the crowdsourced data must be obtained separately from the CodaLab competitions.
- Small demographic subgroups may yield unstable CCC estimates (the paper reports CCC turning negative for two race categories), so sample counts per group must be inspected alongside CCC values.
- Findings are specific to the NewsEmp24 dataset and the LLM-generated labels provided in data/llm-generated-labels; disparity patterns may differ for other datasets or prompts.
