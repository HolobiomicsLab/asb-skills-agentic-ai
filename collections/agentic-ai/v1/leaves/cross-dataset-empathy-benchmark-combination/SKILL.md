# cross-dataset-empathy-benchmark-combination

## Summary

Combines the NewsEmp22, NewsEmp23, and NewsEmp24 empathy benchmark training sets into one training corpus and fine-tunes RoBERTa on LLM-corrected labels (Llama labels, alpha=4.0) to reproduce the state-of-the-art PCC of 0.648 on the NewsEmp24 test set (corrected Table VIII).

## When to use

Use when the goal is to reproduce or exceed the state-of-the-art empathy prediction scores (PCC/CCC/RMSE) on the NewsEmp24 test set by training on the combined NewsEmp24+23+22 data with noise-mitigated labels.

## When NOT to use

- The task targets other NewsEmp experiments, e.g. the baseline with crowdsourced (CS) labels (y(202x) logs, Table II) or the training data augmentation scenario (y_llm(202x) logs, Table III) rather than the combined noise-corrected configuration.
- DeBERTa-based experiments are required — those were conducted with torch 2.2.0 / Python 3.10.12 / ROCm 5.7.3, a different environment than the RoBERTa torch 2.4.1 stack.
- Only a single NewsEmp year's data is available and no LLM-generated labels can be matched by instance IDs, so the combined noise-mitigated setup cannot be instantiated.

## Inputs

- NewsEmp22 training data (from CodaLab competition 834)
- NewsEmp23 training data (from CodaLab competition 11167)
- NewsEmp24 training data (from CodaLab competition 18810)
- Llama-generated empathy labels in data/llm-generated-labels, keyed by instance IDs (message IDs, article IDs, speaker IDs)
- config/config_common.yaml (pre-trained model and label column specification)
- config/config_test.yaml (checkpoint path, e.g. *.ckpt under logs/)

## Outputs

- Fine-tuned RoBERTa checkpoint (*.ckpt) under logs/, e.g. logs/20241115_005338_y'(2024,2022)-ImprovedEarlyStop-MultiAlpha/lr_3e-05_bs_16/alpha_4.0
- NewsEmp24 test-set predictions from src/test.py
- Peak evaluation metrics over three runs: PCC 0.648, CCC 0.597, RMSE 0.021 (corrected Table VIII)

## How to apply

Download the NewsEmp22, NewsEmp23, and NewsEmp24 datasets from their CodaLab competition pages (competitions 834, 11167, 18810) and merge them into the combined training configuration, since redistribution is restricted and only LLM-generated labels in data/llm-generated-labels are shipped with the repo, matched back to source data by instance IDs. Set up the environment on Python 3.12.3 with torch 2.4.1 and ROCm 6.1 via `python -m pip install requirements_torch_rocm.txt` plus `pip install -r requirements.txt`. Edit config/config_common.yaml to specify RoBERTa as the pre-trained model and name the LLM-generated vs crowdsourced label columns, then fine-tune with the lr_3e-05_bs_16 MultiAlpha configuration (alpha=4.0 label correction), e.g. via the job_test.sh SLURM script on the Pawsey Setonix cluster. After training, configure config/config_test.yaml (e.g. test_from_ckpts_parent_dir= logs/20241115_005338_y'(2024,2022)-ImprovedEarlyStop-MultiAlpha/lr_3e-05_bs_16/alpha_4.0) and run python src/test.py to obtain test predictions, then report peak PCC, CCC, and RMSE across three runs (maximum PCC/CCC, minimum RMSE) alongside the re-implemented Giorgi et al. baseline.

## Evaluation signals

- Peak PCC on the NewsEmp24 test set must equal 0.648 and peak CCC 0.597 (corrected Table VIII), with peak RMSE 0.021 (minimum over three runs).
- The proposed method must outperform the re-implemented Giorgi et al. baseline (PCC 0.629 published / 0.607 corrected) on all three evaluation metrics: PCC, CCC, and RMSE.
- The logging directory name must follow the y'(202x) convention for the label-correction scenario, e.g. logs/20241115_005338_y'(2024,2022)-ImprovedEarlyStop-MultiAlpha/lr_3e-05_bs_16/alpha_4.0.
- LLM-generated labels from data/llm-generated-labels must be successfully matched back to the source datasets by their instance identifiers (message IDs, article IDs, speaker IDs).
- Metrics are reported as peak scores across five random runs (maximum PCC/CCC, minimum RMSE over three runs), matching the paper's corrected reporting convention.

## Limitations

- The NewsEmp datasets themselves are not redistributable; only LLM-generated labels aligned with original dataset IDs ship in the repository, so the full combined training corpus must be obtained from the three CodaLab competition pages.
- The published paper's Tables V and VIII contained minor errors in reported peak RMSE scores; only the corrected values in the README (PCC 0.648, CCC 0.597) reflect the true performance.
- Experiments target AMD GPU infrastructure (ROCm 6.1, Pawsey Setonix SLURM cluster via job_test.sh); results depend on running the lr_3e-05_bs_16 MultiAlpha configuration at alpha=4.0.
