# ccc-metric-computation

## Summary

Computes the Concordance Correlation Coefficient (CCC) between crowdsourced and LLM-generated empathy labels, optionally stratified by annotator demographic groups (gender, education, race, age, income), to quantify label agreement and demographic disparity in the NewsEmp benchmarks.

## When to use

Use when two sets of numeric empathy labels for the same instances (e.g., crowdsourced labels from a CodaBench/CodaLab NewsEmp competition and LLM-generated labels from data/llm-generated-labels) must be compared for agreement, overall or per demographic subgroup.

## When NOT to use

- The goal is model predictive accuracy (RMSE/PCC of a trained RoBERTa or DeBERTa model) rather than inter-source label agreement — use the paper's training/testing pipeline instead.
- The two label sets are not aligned on shared instance identifiers (e.g., no message/article/speaker IDs), so a valid join cannot be formed.
- Only one annotation source is available, so there is nothing to correlate.

## Inputs

- Crowdsourced empathy labels for NewsEmp24 downloaded from the CodaLab competition 18810
- LLM-generated label files under data/llm-generated-labels in the LLMPathy repository, each pairing generated labels with instance identifiers (message IDs, article IDs, speaker IDs)
- Annotator demographic metadata (gender, education, race, age, income) keyed on the same instance/annotator identifiers

## Outputs

- demographic_disparity_ccc.csv containing per-demographic-group CCC values and sample counts
- Per-group agreement interpretation (e.g., CCC similar across gender and education but varying widely — even negative — for two race categories)

## How to apply

Load the crowdsourced labels obtained from the CodaLab competition (NewsEmp24, competition 18810) and the LLM-generated label files under data/llm-generated-labels, which pair generated labels with instance identifiers (message IDs, article IDs, speaker IDs), using Python 3.10.12 with pandas. Merge crowdsourced labels, LLM-generated labels, and annotator demographic metadata (gender, education, race, age, income) on the shared instance identifiers via a pandas join keyed on the dataset-specific IDs. Stratify the joined records by each demographic attribute to form subgroups, then compute the CCC within each group alongside the number of samples contributing to that group. Write the per-group CCC values and group sample counts to demographic_disparity_ccc.csv. The CCC is chosen because it penalizes both imprecision (scatter) and inaccuracy (scale/offset shifts), making it more informative than raw Pearson correlation when comparing label sources.

## Related tools

- **Python** (Runtime (Python 3.10.12) used to load, join, stratify, and compute per-group CCC between label sources) — https://github.com/hasan-rakibul/LLMPathy
- **pandas** (Merging crowdsourced labels, LLM-generated labels, and demographic metadata on shared instance identifiers; grouping by demographic attribute)

## Examples

```
df = pd.merge(crowd, llm, on='instance_id'); out = df.groupby('race').apply(lambda g: pd.Series({'ccc': ccc(g.label_cs, g.label_llm), 'n': len(g)})); out.to_csv('demographic_disparity_ccc.csv')
```

## Evaluation signals

- The output file demographic_disparity_ccc.csv exists and contains both ccc and sample-count fields.
- Every computed CCC lies within the mathematically valid range [-1, 1].
- Each reported group count equals the number of joined records for that demographic group (join completeness check).
- Per-group CCCs reproduce the paper's qualitative pattern: similar agreement across gender and education, but wide variation across race, age, and income groups.
- Instance counts after the pandas join match the original label file sizes, confirming no identifiers were dropped or duplicated during merging.

## Limitations

- Full NewsEmp datasets cannot be redistributed in the repository; only LLM-generated labels aligned to dataset IDs are provided, so users must obtain the original datasets from CodaLab (competitions 834, 11167, 18810) and match them back.
- Small demographic subgroups can yield unstable or even negative CCC estimates; sample counts should always be reported alongside CCC values.
- Reported peak RMSE values in the published paper's Tables V and VIII contained minor errors (corrected in the README), so published numbers should be cross-checked against the repository.
