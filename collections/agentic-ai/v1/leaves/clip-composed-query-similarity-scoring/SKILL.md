# clip-composed-query-similarity-scoring

## Summary

Scores composed image retrieval queries by embedding a reference image + text prompt into CLIP's joint space (via SEARLE textual inversion) and computing cosine similarities against pre-computed database embeddings, yielding ranked top-k results and ideal-anchored re-ranking scores for LLM-generated prompt variants.

## When to use

Use when a composed query (reference image I_ref + natural language prompt T) must be matched to candidate images in a CLIP embedding space, or when alternative prompt variants T' need re-ranking against a user-selected ideal target image I* via s = sim(f_c(I_ref, T'), f_i(I*)).

## When NOT to use

- The analysis goal is diagnosing style bias in embedding projections (images cluster by artistic style rather than semantics) — use the debiased UMAP pipeline (Style Debiasing, Contrastive Debiasing, ICA) instead
- The retrieval task is not composed image retrieval (no reference image + text pair), since the scoring depends on SEARLE textual inversion into CLIP's joint space
- Only unimodal explainability (saliency/token attribution) is needed without any ranking or prompt-variant comparison

## Inputs

- Reference image I_ref (user-uploaded, e.g. PNG/JPG)
- Natural language modification prompt T (e.g. 'wearing a red collar')
- Pre-computed CLIP database image embeddings (e.g. ImageNet-R, up to 30,000 images)
- User-selected ideal target image(s) I* from the top-k results
- Candidate prompt variants T' generated by Mistral-7B-Instruct-v0.2

## Outputs

- Ranked top-k image list with cosine similarity scores
- Ideal-anchored similarity scores s = sim(f_c(I_ref, T'), f_i(I*)) per prompt variant
- Per-candidate retrieval metrics: NDCG@K, mAP@K, MRR, Coverage, Mean Rank, Mean Similarity
- Rank-delta values feeding the Ideal-anchored Rank-Δ heatmap

## How to apply

First, pass the reference image I_ref through a zero-shot SEARLE textual-inversion model (ViT-B/32 or ViT-L/14 CLIP backbone, 'targetpad' preprocessing) to obtain a pseudo-token within CLIP's text embedding space, and compose it with the user prompt T to form the composed-query embedding f_c(I_ref, T). Compute cosine similarities between this vector and the pre-computed CLIP database embeddings (dataset e.g. ImageNet-R, up to 30,000 images sampled via DATASET_SAMPLE_SIZE) and rank to return the top-k results. For prompt refinement, condition Mistral-7B-Instruct-v0.2 on I_ref, T, and the visual context of user-selected ideal images I* (ENHANCEMENT_USE_CONTEXT = True) to generate 10 candidate prompt variants (ENHANCEMENT_CANDIDATE_PROMPTS = 10), then score each variant with the ideal-anchored similarity s = sim(f_c(I_ref, T'), f_i(I*)). Evaluate each variant with NDCG@K, mAP@K, MRR, Coverage, Mean Rank and Mean Similarity, and verify empirical effect through the Ideal-anchored Rank-Delta heatmap loop. The rationale is that CLIP's joint image-text space lets a single cosine score express composed-query-to-image relevance, making ranking changes directly attributable to prompt edits.

## Evaluation signals

- The exported enhanced_prompt_variants file exists, is valid JSON, and contains exactly ENHANCEMENT_CANDIDATE_PROMPTS = 10 well-formed candidate prompt entries
- Each candidate entry includes grounding inputs: reference image identifier, original prompt, and ideal-image identifiers
- Each candidate prompt is a well-formed textual modifier that can be re-ranked against the ideal anchor via s = sim(f_c(I_ref, T'), f_i(I*))
- Rankings are reproducible: cosine similarities between the composed vector and pre-computed database embeddings reproduce the top-k ordering shown in the Query Results Panel
- Prompt variants show empirically verifiable ranking changes of the selected ideal image through the Ideal-anchored Rank-Δ heatmap and NDCG/mAP/MRR metrics

## Limitations

- CLIP-based embedding spaces suffer from style bias, where UMAP projections cluster images by artistic style rather than semantic categories, which can distort similarity-based reasoning
- Scalability is limited: the scatterplot shows at most MAX_IMAGES_ON_SCATTERPLOT = 100 images and the dataset is capped at DATASET_SAMPLE_SIZE = 30,000 images
- CIR model support is limited to SEARLE-family and OTI methods; extending model support, scalability and personalization is deferred to future work
