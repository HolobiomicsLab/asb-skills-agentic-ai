# survey-response-topic-characterization

## Summary

Qualitatively characterizes topics extracted from survey free-text responses by cross-technique comparison of MALTopic, LDA, and BERTopic outputs, using sentence-embedding cosine similarity and agglomerative clustering to test whether a multi-agent LLM framework separates semantically distinct themes (e.g., job-market entry challenges vs. job-displacement concerns) that baselines collapse.

## When to use

Use when you need to verify that topic-model outputs on survey data separate two semantically distinct themes that baseline topic models (LDA, BERTopic) merge, via embedding-similarity clustering of topic labels and keywords.

## When NOT to use

- The input is raw survey text rather than already-generated topic lists from MALTopic, LDA, and BERTopic — run the topic-modeling pipelines first
- The goal is purely quantitative scoring (coherence/diversity metrics) rather than qualitative cross-technique topic distinctness analysis
- The dataset is not survey free-text with structured respondent data, since MALTopic's enrichment agent relies on structured data to enhance textual responses

## Inputs

- Topic lists (topic labels + representative keywords) generated by MALTopic, LDA, and BERTopic on a survey dataset
- Survey free-text responses with structured respondent metadata used by the enrichment agent
- Sentence-transformer model for encoding topic labels and keywords

## Outputs

- topic_similarity_matrix.csv — pairwise cosine-similarity matrix across all topics from the three techniques
- topic_separation_report.csv — cluster membership per technique and similarity scores within and between job-related topic groups

## How to apply

Load the generated topic lists (labels plus representative keywords) for MALTopic, LDA, and BERTopic from the survey-dataset pipeline outputs of the yash91sharma/MALTopic repository. Encode every topic into dense sentence embeddings with a sentence-transformer model and compute the pairwise cosine-similarity matrix across all topics from the three techniques, saving it as topic_similarity_matrix.csv. Apply agglomerative hierarchical clustering with cosine distance on the embedded topics to group semantically related topics across techniques, then examine the job-related clusters: the claim is supported if MALTopic's topics split into two distinct groups (entry-challenge vs. displacement concerns) while LDA and BERTopic topics collapse into one mixed cluster. Summarize cluster membership per technique and within/between-group similarity scores in topic_separation_report.csv, recording agreement or disagreement with the paper's Section VI.B / Table IV interpretability claim. The OpenAI Python library provides the LLM client layer for the multi-agent MALTopic pipeline (enrichment, topic-modeling, and deduplication agents).

## Evaluation signals

- Agglomerative clustering with cosine distance reproduces two distinct job-related topic groups for MALTopic (entry-challenge vs. displacement concerns)
- LDA and BERTopic job-related topics collapse into one mixed cluster, consistent with the paper's claimed interpretability advantage
- topic_similarity_matrix.csv contains finite cosine-similarity scores for every cross-technique topic pair
- topic_separation_report.csv lists cluster membership for each technique with within- vs. between-group similarity scores
- If clustering disagrees with the expected split, the report records the disagreement with the Section VI.B / Table IV claim rather than silently passing

## Limitations

- Validation is qualitative and dataset-specific (survey responses about job-related concerns); the two-topic split may not generalize to other corpora
- Results depend on the sentence-transformer embeddings and cosine-distance clustering choices, which could alter cluster assignments
- MALTopic's multi-agent pipeline requires access to an LLM API (OpenAI client) and structured data for the enrichment agent
