# episode-metric-aggregation-and-auc-computation

## Summary

Aggregates per-episode RL training logs (episode_metrics_*.csv) into per-method summary metrics — reward AUC, success rate, average steps to goal, average reward, total wins, total steps — and writes a cross-method, cross-environment comparison (experiment_auc_summary.csv) matching the paper's Table II.

## When to use

Use when you have episode-level CSV logs from multiple RL agents (e.g., ULPS, PPO, Q-Learning, DQN) across grid sizes and must build a consolidated per-method comparison table with reward AUC and success rates.

## When NOT to use

- You only need raw episode-level trajectories or entropy/calibration diagnostics, not a cross-method summary table
- Your runs used different episode counts, seeds, or episode caps, so AUC and success-rate comparisons against the paper's baselines would not be like-for-like

## Inputs

- episode-level CSV logs (episode_metrics_*.csv) per method and grid size
- entropy logs (entropy_values_*.csv)
- calibration metrics (calibration_metrics_*.csv)
- output folder structure used during the experiments (results/)

## Outputs

- consolidated comparison table experiment_auc_summary.csv (one row per method per grid size with reward AUC, success rate, average steps to goal, average reward, total wins, total steps)
- final training summary plots (final_training_summary_*.png)
- per-method summary metrics matching Table II columns

## How to apply

Collect the episode-level logs (episode_metrics_*.csv), entropy logs (entropy_values_*.csv), and calibration metrics (calibration_metrics_*.csv) generated by run_4x4_experiment.py and run_8x8_experiment.py for each agent under identical settings (1000 episodes, seed 42, 50-step episode cap). For each method and grid size (4x4 and 8x8 MiniGrid-UnlockPickup), compute reward AUC, success rate, average steps to goal, average reward, total wins, and total steps so the summary columns match Table II. Write one row per method per grid size to experiment_auc_summary.csv and generate final training summary plots (final_training_summary_*.png) from the same result files. Validate that ULPS rows show higher reward AUC and success rate than the unguided PPO, uncalibrated LLM, Q-Learning, and DQN baselines, consistent with the paper's reported improvements.

## Related tools

- **ULPS** (Primary agent whose episode logs (Calibrated LLM + PPO) are aggregated and compared against baselines via reward AUC and success rate)
- **Proximal Policy Optimization (PPO)** (Learned policy underlying ULPS logs and the Unguided PPO baseline whose per-episode metrics enter the AUC summary)
- **MiniGrid** (UnlockPickup benchmark environment whose 4x4 and 8x8 grid sizes define the two environments compared in the summary table)

## Examples

```
python MainCode/run_8x8_experiment.py  # then aggregate episode_metrics_*.csv into experiment_auc_summary.csv (one row per method per grid size)
```

## Evaluation signals

- experiment_auc_summary.csv exists with exactly one row per method per grid size (each agent x {4x4, 8x8})
- Summary columns match Table II: reward AUC, success rate, average steps to goal, average reward, total wins, total steps
- ULPS rows show higher reward AUC and success rate than Unguided PPO, Uncalibrated LLM, Q-Learning, and DQN baselines
- In the 8x8 environment, aggregated success rates are consistent with reported values: ULPS ~99.7%, uncalibrated LLM ~72.3%, PPO alone nearly zero
- Final plots final_training_summary_*.png are produced from the same results/ output folder structure

## Limitations

- Not all result files are regenerated automatically by a single script; some CSV files and plots were pre-generated during experimentation and shipped under results/
- Plotting and summarization scripts assume the same output folder structure used during the experiments
- Only a subset of development plots was selected for the final paper, so reproducing all paper figures may require extra path adjustments
