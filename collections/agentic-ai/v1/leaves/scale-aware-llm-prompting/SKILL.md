# scale-aware-llm-prompting

## Summary

Generates empathy labels by prompting an LLM with a psychology-based, scale-aware template that asks for 1.0–7.0 scores on Batson's six empathy emotions (sympathetic, moved, compassionate, tender, warm, softhearted), averaged into a single y* label per essay. Used to replace or supplement crowdsourced labels on the NewsEmp22/23/24 benchmarks.

## When to use

Use when empathy training data has noisy crowdsourced labels or needs augmentation, and essay texts (NewsEmp22/23/24) must be re-labelled with psychology-grounded numeric scores via an LLM.

## When NOT to use

- The dataset labels are already clean crowdsourced empathy scores and the goal is a baseline run (y(202x)) rather than label correction or augmentation
- The task is downstream PLM training/testing on existing LLM-generated labels rather than generating those labels (use the repository's test workflow instead)
- The emotion taxonomy is not Batson's six subscales — the 1.0–7.0 scale-aware prompt is specific to sympathetic, moved, compassionate, tender, warm and softhearted

## Inputs

- Essay texts with instance identifiers from NewsEmp22 (https://codalab.lisn.upsaclay.fr/competitions/834), NewsEmp23 (https://codalab.lisn.upsaclay.fr/competitions/11167), and NewsEmp24 (https://codalab.lisn.upsaclay.fr/competitions/18810)
- Batson six-subscale emotion template (Table I of the paper)
- LLM-generated label column name from config/config_common.yaml

## Outputs

- Per-instance records (instance identifier, six Batson subscale scores, averaged y*) written to data/llm-generated-labels
- LLM-generated label files aligned to original dataset IDs for downstream RoBERTa/DeBERTa training (y_llm second application scenario)

## How to apply

Load the essay texts with their instance identifiers (message IDs, article IDs, speaker IDs) from the NewsEmp22, NewsEmp23 and NewsEmp24 Codalab competitions. Build a scale-aware prompt per essay by pairing the essay text with Batson's six-subscale template (sympathetic, moved, compassionate, tender, warm, softhearted) from Table I of the paper. Query the LLM with deterministic sampling (temperature 0, top_p 0.01) so each essay returns exactly six comma-separated numeric scores on the 1.0–7.0 subscale range, then verify six numeric values were parsed and average them into a single empathy score y* per instance. Align each y* with its instance identifier and write records to the data/llm-generated-labels directory, with column names consistent with the LLM-generated label column configured in config/config_common.yaml (the y_llm label used in the second application scenario).

## Related tools

- **Python** (Implementation language for building the scale-aware prompts, querying the LLM, parsing the six scores, averaging into y*, and writing label files)
- **pip** (Installs the repository dependencies required for the labelling pipeline (pip install -r requirements.txt))

## Examples

```
pip install -r requirements.txt && python src/test.py  # after setting the LLM-generated label column in config/config_common.yaml
```

## Evaluation signals

- The output file exists in data/llm-generated-labels and every record contains an instance identifier plus six subscale scores and the averaged y*
- Each parsed response contains exactly six numeric values (verified after parsing)
- All six subscale scores fall within the valid 1.0–7.0 range
- Label-column naming in the output matches the LLM-generated label column configured in config/config_common.yaml (consistent with y_llm naming such as y_llm(202x))
- Downstream RoBERTa training with these labels improves Pearson correlation over crowdsourced-label baselines (paper reports state-of-the-art PCC of 0.648 on NewsEmp benchmarks)

## Limitations

- The public NewsEmp datasets restrict redistribution, so only the LLM-generated labels (aligned to original dataset IDs) are shipped in the repository; the full essays must be fetched from the Codalab competition pages to regenerate or validate labels
- Deterministic sampling (temperature 0, top_p 0.01) is required for reproducibility; other sampling settings may produce non-replicable six-score outputs
- The README notes reporting errors in peak RMSE values in Tables V and VIII of the published paper, so published RMSE comparisons may be stale (corrected tables in README)
