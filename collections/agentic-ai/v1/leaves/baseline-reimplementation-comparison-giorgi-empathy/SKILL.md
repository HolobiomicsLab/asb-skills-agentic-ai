# Baseline Reimplementation Comparison (Giorgi et al. Empathy)

## Summary

Re-implements the Giorgi et al. empathy-prediction baseline alongside the noise-mitigated RoBERTa approach on the NewsEmp24+23+22 combined training data so that peak PCC, CCC, and RMSE scores can be compared directly against the prior state of the art (Giorgi et al., PCC 0.629/0.607).

## When to use

Use when benchmarking a new empathy-prediction model on the NewsEmp24 test set and you need a head-to-head comparison against the Giorgi et al. baseline under identical metrics (PCC, CCC, RMSE).

## When NOT to use

- When the goal is the paper's second application scenario (training-data augmentation with LLM labels, e.g. y(202x)+y_llm(202y)) rather than noisy label correction with alpha=4.0
- When evaluating on a non-NewsEmp dataset, since the 0.648 PCC state-of-the-art claim and Giorgi et al. comparison are specific to the NewsEmp24 test set

## Inputs

- NewsEmp22, NewsEmp23, and NewsEmp24 datasets from their CodaLab competition pages, merged into the combined training configuration
- Llama-generated labels from data/llm-generated-labels, aligned with instance IDs (message IDs, article IDs, speaker IDs)
- Trained model checkpoints (*.ckpt files under logs/), e.g. logs/20241115_005338_y'(2024,2022)-ImprovedEarlyStop-MultiAlpha/lr_3e-05_bs_16/alpha_4.0
- config/config_common.yaml and config/config_test.yaml configuration files

## Outputs

- Test-set predictions from python src/test.py
- Peak PCC, CCC, and RMSE scores across three runs for the proposed method and the re-implemented Giorgi et al. baseline
- A Table VIII-style comparison confirming the proposed method (peak PCC 0.648, CCC 0.597) exceeds the Giorgi et al. baseline (PCC 0.607)

## How to apply

First re-implement the Giorgi et al. baseline in the same evaluation harness so metrics are computed identically for both models. Train the proposed noise-mitigated RoBERTa on the merged NewsEmp24+23+22 training data using Llama-generated labels (from data/llm-generated-labels, matched by instance IDs) as noise-corrected targets with annotation-selection threshold alpha=4.0, e.g. via the lr_3e-05_bs_16 MultiAlpha configuration. Run testing by setting config/config_test.yaml to point at the trained .ckpt file and executing python src/test.py to obtain test-set predictions. Compute PCC, CCC, and RMSE over three runs and report the peak scores (maximum PCC/CCC, minimum RMSE), noting that peak RMSE reporting errors were corrected in Tables V and VIII per the README. Validate by checking the peak metrics match the corrected Table VIII values: peak PCC 0.648 and CCC 0.597 for the proposed method, exceeding the Giorgi et al. baseline PCC of 0.607.


## Evaluation signals

- Peak PCC of 0.648 and CCC of 0.597 on the NewsEmp24 test set for the combined NewsEmp24+23+22 noise-mitigated RoBERTa model
- Proposed method's peak PCC must exceed the Giorgi et al. baseline PCC of 0.607 (and the published Giorgi PCC of 0.629)
- Peak scores defined as maximum PCC/CCC and minimum RMSE (corrected values) across three runs, per the corrected Tables V and VIII
- Configured checkpoint path resolves to a valid .ckpt file, e.g. under logs/...lr_3e-05_bs_16/alpha_4.0
- Baseline and proposed model evaluated with identical metric computation (PCC, CCC, RMSE) in the same harness

## Limitations

- Reported scores are peak values across runs, and peak RMSE reporting errors affected Tables V and VIII of the published paper; use the corrected tables from the README
- The original NewsEmp datasets cannot be redistributed; they must be obtained separately from the CodaLab competition pages and matched to LLM-generated labels via instance IDs
- The job_test.sh SLURM workflow is specific to the Pawsey Setonix cluster
