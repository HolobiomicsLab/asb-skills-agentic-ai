# Cross-technique topic clustering

## Summary

Compares topic lists produced by MALTopic, LDA, and BERTopic by embedding each topic (label plus representative keywords) into dense sentence embeddings, computing a pairwise cosine-similarity matrix, and applying agglomerative hierarchical clustering with cosine distance to reveal which topics each technique separates or collapses.

## When to use

Use when you have topic lists (labels + representative keywords) from two or more topic-modeling techniques on the same survey-dataset corpus and need to verify whether one technique resolves distinct themes the others merge.

## When NOT to use

- You only have topic lists from a single technique and no cross-technique comparison is possible
- Topics are not represented as labels with representative keywords, so they cannot be encoded into sentence embeddings
- The corpus is not a survey-style dataset with job-related thematic content where qualitative distinctness of overlapping topics is in question

## Inputs

- Topic lists (topic labels plus representative keywords) generated by MALTopic on the survey dataset
- Topic lists generated by baseline LDA on the same survey dataset
- Topic lists generated by baseline BERTopic on the same survey dataset
- A sentence-transformer model for dense topic embeddings

## Outputs

- topic_similarity_matrix.csv — pairwise cosine-similarity matrix across all topics from the three techniques
- topic_separation_report.csv — cluster membership per technique plus within- and between-group similarity scores for the job-related groups

## How to apply

Load the generated topic lists for MALTopic, LDA, and BERTopic from the survey-dataset pipeline outputs (repo yash91sharma/MALTopic). Encode every topic — label plus representative keywords — into dense sentence embeddings using a sentence-transformer model. Compute the pairwise cosine-similarity matrix across all topics from the three techniques and save it as topic_similarity_matrix.csv. Apply agglomerative hierarchical clustering with cosine distance on the embedded topics to group semantically related topics across techniques. Inspect the job-related clusters and check whether MALTopic's topics split into two distinct groups (job-market entry challenges for students/inexperienced respondents vs. job-displacement concerns of experienced professionals) while LDA and BERTopic topics collapse into one mixed cluster. Summarize cluster membership per technique and within/between-group similarity scores in topic_separation_report.csv.

## Related tools

- **MALTopic** (Source of the enriched, human-readable topic lists whose interpretability advantage (two distinct job-related topics) is being validated against baselines) — https://github.com/yash91sharma/MALTopic
- **BERTopic** (Baseline topic-modeling technique whose topic list is embedded and clustered alongside MALTopic's to test whether it fails to separate the two job-related topics)

## Examples

```
from sklearn.cluster import AgglomerativeClustering; labels = AgglomerativeClustering(n_clusters=2, metric='cosine', linkage='average').fit_predict(topic_embeddings)
```

## Evaluation signals

- Agglomerative clustering with cosine distance reproduces two distinct job-related topic groups for MALTopic (entry-challenge vs. displacement concerns), consistent with the paper's Section VI.B / Table IV claim
- The LDA and BERTopic topic lists collapse the job-related content into one mixed cluster rather than two distinct groups
- topic_similarity_matrix.csv contains pairwise cosine similarities for every topic from all three techniques with no missing cells
- topic_separation_report.csv records cluster membership per technique and similarity scores within and between the job-related groups; if the claim is not reproduced, the report explicitly records the disagreement

## Limitations

- Validation is qualitative and depends on semantic judgment of the job-related clusters; if clustering does not reproduce the two-group split, the result must be recorded as disagreement with the Section VI.B / Table IV claim rather than forced
- Results depend on the choice of sentence-transformer embedding model and agglomerative-linkage settings, which are not fixed by the paper
- The skill targets the survey dataset used in the MALTopic evaluation; coherence/diversity/interpretability advantages were shown only there, so transfer to other corpora is untested
