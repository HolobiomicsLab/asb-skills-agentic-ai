# Training-curve and radar visualization

## Summary

Produces the paper's Fig. 2 average-reward training trajectories and Fig. 3 reward/success/steps/AUC radar comparison from episode-level CSV logs, enabling visual comparison of the calibrated ULPS model against Unguided PPO, Linear Decay, Q-Learning, and DQN baselines.

## When to use

Use when episode-level RL training logs (episode_metrics_*.csv) and reward AUC summaries (experiment_auc_summary.csv) must be turned into training-trajectory plots and radar charts comparing ULPS vs baselines.

## When NOT to use

- Results directories are pre-generated under results/ and only a subset of plots was selected for the paper — do not expect every development plot to be regenerated by a single script.
- The task is numeric comparison of final metrics only (e.g. AUC tables) with no need for trajectory or radar visualization.

## Inputs

- episode_metrics_*.csv (episode-level logs: reward, success, steps per method)
- entropy_values_*.csv
- calibration_metrics_*.csv
- experiment_auc_summary.csv (consolidated reward AUC per method)

## Outputs

- final_training_summary_*.png (Fig. 2 average-reward training trajectories; Fig. 3 radar comparison)
- experiment_auc_summary.csv (consolidated AUC summary)

## How to apply

Run the ULPS experiment runners (MainCode/run_4x4_experiment.py and run_8x8_experiment.py) and train the baselines (Unguided PPO, Linear Decay, Q-Learning, DQN) on the same MiniGrid-UnlockPickup environments and sparse reward function (+0.5 key pickup, +0.5 door opening, +0.2 goal reach, -0.02 invalid action penalty, plus step-based bonus). Collect the generated episode_metrics_*.csv, entropy_values_*.csv, and calibration_metrics_*.csv logs, then compute the reward AUC for each method and consolidate it into experiment_auc_summary.csv. Plot the average-reward training trajectory for all methods (Fig. 2) and the reward/success/steps/AUC radar comparison of the calibrated model versus baselines (Fig. 3), saving figures as final_training_summary_*.png. Note the README warns that plotting scripts assume the same output folder structure used during the experiments, so paths may need adjustment.

## Related tools

- **ULPS** (Calibrated LLM + PPO agent whose training runs produce the episode-level CSV logs and summaries being visualized.) — https://github.com/USD-AI-ResearchLab/uncertainty-aware-llm-rl
- **Proximal Policy Optimization (PPO)** (Learned policy trained alongside LLM guidance; one of the methods plotted in the training trajectories and radar chart.)
- **MiniGrid** (MiniGrid-UnlockPickup benchmark (4x4 and 8x8) on which all compared agents are trained before visualization.)
- **BERT (bert-base-uncased)** (Fine-tuned LLM action predictor inside ULPS; its calibration metrics feed the calibration_metrics_*.csv logs used by the visualization pipeline.)

## Examples

```
python MainCode/run_4x4_experiment.py  # then run plotting/summarization over results/ to emit experiment_auc_summary.csv and final_training_summary_*.png
```

## Evaluation signals

- final_training_summary_*.png figures reproduce the qualitative result that ULPS achieves higher reward AUC and success rate with fewer environment interactions than the baselines.
- experiment_auc_summary.csv shows the calibrated model with the highest reward AUC (2055.08 in the 4x4 environment).
- Episode-level logs contain average steps to goal consistent with the reported value (7.24) for the calibrated model in the 4x4 MiniGrid environment.
- Plotting scripts run only after the expected output folder structure (results/ with episode_metrics_*.csv, entropy_values_*.csv, calibration_metrics_*.csv) is in place.
- All compared methods were trained on the same environments and the same sparse reward function, so trajectories are comparable.

## Limitations

- Not all result files are regenerated automatically by a single script; some CSV files and plots were pre-generated during experimentation.
- Some plotting and summarization scripts assume the same output folder structure used during the experiments and may require minor path adjustments.
- Several additional plots were generated during development, but only a subset was selected for the final paper for compactness; no changelog exists.
